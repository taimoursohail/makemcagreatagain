> A modern, high-converting, dynamic WebGL-powered landing page built specifically for the alternative finance (MCA — Merchant Cash Advance) industry. Designed for ultra-fast lead intake, ISO agreement requests, and direct file submissions for $100k+ monthly revenue business files.

---

## Features

- **Modern Dark Navy & Gold Aesthetic:** Premium, high-integrity design tailored for high-ticket MCA brokers and ISOs.
- **Interactive WebGL Shader Background:** Dynamic canvas-based animated background (`WebGL`) with custom fragment shaders and interactive mouse distortion.
- **Dual-Trigger Onboarding Form:** Toggle between *Underwriting Guidelines Request* and *ISO Agreement Request* directly within a single form component.
- **Fully Responsive & Mobile-Optimized:** Custom Off-Canvas Mobile Navigation Drawer built with pure JavaScript (zero external UI library lock-in).
- **Embedded Media & Social Hub:** Integrated YouTube video showcases, direct email widgets, floating CTA popups, and verified partner review cards.
- **Dynamic FAQ Accordion:** Interactive, zero-dependency JavaScript accordion for seamless browsing.
- **Built-in Social Impact Section:** Highlighting community reinvestment and local business support initiatives ("Doing Good in the Hood").

---

## Tech Stack & Dependencies

- **HTML5 & Modern Semantic Markup**
- **Tailwind CSS (v3 via CDN):** Customized design system, custom dynamic color palette, typographic scales, and container queries.
- **Google Fonts & Symbols:** `Montserrat` (Headlines), `Inter` (Body Text), `Work Sans` (Labels), and `Material Symbols Outlined`.
- **Vanilla JavaScript:** WebGL shader pipeline, off-canvas menu toggles, and accordion interactions.
